
# NBA Fantasy Lab

Local NBA Fantasy Basketball analytics application.

## Project

- League: Koszobidon Fantasy
- Platform: ESPN Fantasy Basketball
- Season: 2026/27
- Teams: 12
- Format: Head to Head Each Category
- Draft: Snake, 13 rounds
- Pick timer: 90 seconds

## Scoring Categories

PTS, REB, AST, STL, BLK, 3PM, FG%, FT%, TO, TW

- TO: Lower is better.
- TW: Team Wins (ESPN rules to be verified).

## Technology Stack

- Python 3.11+
- Streamlit
- SQLite
- Pandas
- NumPy
- Plotly
- pytest
